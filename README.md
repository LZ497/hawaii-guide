# Hawaii Travel Guide

Static GitHub Pages site for the May 23-31, 2026 Hawaii trip.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Push this folder to the new repository.
3. In GitHub, open `Settings` -> `Pages`.
4. Set source to `Deploy from a branch`, branch `main`, folder `/root`.
5. Open `https://<username>.github.io/<repo-name>/`.

The guide is a single `index.html` file and does not require any build step.
